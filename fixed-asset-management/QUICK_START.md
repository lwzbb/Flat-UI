# 快速开始指南

## 🚀 3 步快速启动

### 步骤 1: 安装依赖

```bash
cd fixed-asset-management
npm install
```

### 步骤 2: 启动开发服务器

```bash
npm run dev
```

### 步骤 3: 登录系统

打开浏览器访问 `http://localhost:3000`

使用以下任一账户登录（密码：`123456`）：
- **公司领导** - 查看公司整体资产状况
- **资产管理部负责人** - 查看资产管理部视角
- **生产部负责人** - 查看业务部门视角
- **销售部负责人** - 查看业务部门视角

## 📊 三个视角说明

### 1. 公司领导层视角

**关注内容：**
- 公司资产原值、净值
- 当年资本性支出预算
- 当年新增资产价值
- 各资产类别占比

**关键指标：**
- 资产原值总额
- 资产净值总额
- 预算执行率
- 新增资产数量和价值

### 2. 资产管理部视角

**关注内容：**
- 公司整体资产状况（继承领导层视角）
- 资产管理部部门数据
- 采购业务统计
- 待处理事项

**关键指标：**
- 公司整体资产数据
- 部门资产数据
- 采购统计（待审批、已审批、已完成）
- 月度采购趋势

### 3. 业务部门视角

**关注内容：**
- 部门资产原值、净值
- 部门预算执行情况
- 部门资产类型占比
- 预算执行明细

**关键指标：**
- 部门资产总值
- 部门预算执行率
- 各资产类别占比
- 预算执行明细（按类别）

## 🎯 功能亮点

### 数据可视化
- 📊 饼图：资产类别占比
- 📈 柱状图：资产价值对比
- 📉 折线图：采购趋势
- 📋 表格：详细数据统计

### 实时统计
- 自动计算资产总值、净值
- 实时统计预算执行情况
- 动态展示新增资产数据

### 多维度分析
- 按资产类别分析
- 按部门分析
- 按时间维度分析（月度采购趋势）

## 💡 使用技巧

### 查看详细数据
- 点击表格可以查看详细数据
- 图表支持交互，可以查看具体数值

### 切换部门视角
- 在业务部门视角页面，可以通过下拉菜单切换不同部门
- 查看各部门的资产和预算情况

### 理解数据含义
- **原值**：资产购买时的原始价值
- **净值**：原值减去累计折旧后的价值
- **预算执行率**：已使用预算 / 总预算 × 100%

## 🔧 常见问题

### Q: 如何修改数据？
A: 编辑 `src/data/mockData.js` 文件，修改模拟数据生成逻辑。

### Q: 如何添加新用户？
A: 编辑 `src/hooks/useAuth.js` 文件，在 `mockUsers` 数组中添加新用户。

### Q: 如何连接真实后端？
A: 修改 `src/data/mockData.js` 中的数据获取函数，改为调用 API。

### Q: 如何自定义样式？
A: 修改各组件对应的 CSS 文件，或使用 Ant Design 的主题定制功能。
