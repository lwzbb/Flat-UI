# 固定资产管理系统

一个基于 React 的固定资产管理系统，提供多层级视角的数据展示和分析功能。

## 🎯 项目概述

本系统为固定资产管理提供三个不同管理层级的视角：

1. **公司领导层视角** - 关注公司整体资产状况、预算执行、资产类别占比
2. **资产管理部视角** - 包含领导层关注内容 + 部门业务数据（采购、审批等）
3. **业务部门视角** - 关注本部门资产状况、预算执行情况、资产类型占比

## ✨ 核心功能

### 公司领导层视角
- ✅ 公司资产原值、净值统计
- ✅ 当年资本性支出预算及执行情况
- ✅ 当年新增资产价值统计
- ✅ 各资产类别占比分析（饼图、柱状图）
- ✅ 资产类别详细统计表格

### 资产管理部视角
- ✅ 公司整体资产状况（继承领导层视角）
- ✅ 资产管理部部门数据
- ✅ 采购业务统计（待审批、已审批、已完成）
- ✅ 月度采购趋势分析
- ✅ 待处理事项提醒
- ✅ 采购明细表格

### 业务部门视角
- ✅ 部门资产原值、净值统计
- ✅ 部门预算执行情况（总预算、已使用、剩余）
- ✅ 部门资产类别占比分析
- ✅ 预算执行情况可视化（按类别）
- ✅ 资产类别统计表格
- ✅ 预算执行明细表格

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 `http://localhost:3000` 查看应用。

### 构建生产版本

```bash
npm run build
```

## 🛠️ 技术栈

- **React 18** - UI 框架
- **React Router** - 路由管理
- **Ant Design** - UI 组件库
- **ECharts** - 数据可视化
- **Vite** - 构建工具

## 📊 数据模型

### 资产数据
- 资产基本信息（名称、类别、部门）
- 资产价值（原值、净值）
- 资产状态（正常、维修中等）
- 采购年份、是否当年新增

### 预算数据
- 部门预算
- 资产类别预算
- 预算执行情况（已使用、剩余、执行率）

### 采购数据
- 采购申请信息
- 采购状态（待审批、已审批、采购中、已完成、已取消）
- 月度采购趋势

## 🎨 功能特点

### 1. 多层级权限
- 不同角色看到不同的数据视图
- 自动路由到对应视角

### 2. 数据可视化
- 饼图展示资产类别占比
- 柱状图对比资产价值
- 折线图展示采购趋势
- 进度条显示预算执行率

### 3. 实时统计
- 自动计算资产总值、净值
- 实时统计预算执行情况
- 动态展示新增资产数据

### 4. 响应式设计
- 适配不同屏幕尺寸
- 移动端友好

## 📈 数据展示

### 统计指标
- 资产原值、净值
- 预算总额、已使用、剩余
- 预算执行率
- 新增资产数量和价值

### 图表分析
- 资产类别占比饼图
- 资产价值对比柱状图
- 预算执行情况图表

- 资产类别详细统计
- 预算执行明细

## 🔧 配置说明

### 修改数据
编辑 `src/data/mockData.js` 可以：
- 修改资产类别
- 调整部门列表
- 自定义模拟数据生成逻辑

### 添加新用户
编辑 `src/hooks/useAuth.js` 中的 `mockUsers` 数组。

### 自定义样式
修改各组件对应的 CSS 文件。
